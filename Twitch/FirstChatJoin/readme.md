First Chat Join, is similiar to First Words, it however watches when someone, who is in the specified User Groups joins the chat and not write

For this to work properly, you'll need to have Live Update for Twitch checked under Platforms > Twitch > Settings, in the Present Viewers section.

It will create a new custom Trigger Custom> [pwn] Misc > Present Viewers > First Chat Join. An example action using that trigger is already in the import.
